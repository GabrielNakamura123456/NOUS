# NOUS

## Sobre o Projeto

NOUS é uma plataforma inteligente desenvolvida para auxiliar estudantes no apoio emocional e desenvolvimento educacional utilizando Inteligência Artificial.

O projeto foi desenvolvido para a disciplina de Compliance & Quality Assurance utilizando metodologias Scrum no Azure DevOps.

---

## Objetivo

O objetivo da plataforma é oferecer suporte emocional e acadêmico através de:

- Chatbot emocional com IA
- Check-in diário de humor
- Recomendações personalizadas
- Alertas inteligentes
- Histórico emocional
- Dashboard administrativo

---

## Tecnologias Utilizadas

- Java Spring Boot
- React Native + Expo
- Oracle Database
- Oracle OCI Generative AI
- Azure DevOps
- Postman
- Scrum

---

## Metodologia

O gerenciamento do projeto foi realizado utilizando Scrum no Azure DevOps com:

- Epics
- Features
- Product Backlog Items
- Tasks
- Sprint Planning
- Kanban
- Quality Assurance
